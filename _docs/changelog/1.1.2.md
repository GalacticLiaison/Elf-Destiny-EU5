# 1.1.2

Bug Fix: The Aeluran school will no longer accidentally try to recruit non-elf girls — the daughters effect now correctly matches its own trigger

Bug Fix: Daughters already sent to Deepwood for Aeluran training can no longer be recruited a second time — the recruitment event no longer re-fires for the same child, Deepwood no longer re-recruits girls already in training there (which granted repeatable free religious influence), and a trained daughter's home country is no longer overwritten so she now correctly returns home as an adult

Bug Fix: Calaquendi estate buildings (Mallorn Tree Grove, Baths of Starlight, Perfume Garden of Valinor, Wine Cellar of Elder Days, Feasting Hall of the Trees, Grand Archives) are no longer destroyed when a location upgrades to Megalopolis — they now allow the megalopolis rank

Bug Fix: The Calaquendi parliament sponsor issues can now target megalopolis-rank locations, so realms whose cities have all outgrown city rank no longer lose access to these debates

Bug Fix: The restored Grand Portal no longer disappears when its location is re-evaluated (e.g. on a rank upgrade) — its location requirement accepted only the ruins it replaces, which the restoration event had already destroyed

Loads of minor 1.3 compatibility fixes
