# Elf Destiny unit illustrations.
# Since EU5 1.4 the 2D unit art is chosen by these script entries, not by the texture filename
# (see game/in_game/gfx/unit_illustrations/readme.txt). Without entries every elven unit fell back
# to the vanilla default pictures. One entry per unique unit (priority tier 900000 = is_unit_type),
# plus a category-level fallback for every Magi unit (identity tier, below unit-specific art).
